# Source and dependency provenance

Last reviewed: **2026-08-11**.

## Submission code

- All repository implementation code was written for this project by the
  participant with permitted AI assistance.
- No third-party contestant solution or source-code snippet has been copied.
- The C++ programs use only the ISO C++ standard library. The Python tools use only
  the Python standard library. CMake, the compiler, and sanitizers are build tools,
  not bundled submission dependencies.
- The historical mock's `sample.in` and `sample.out` transcribe the public official
  example for Codeforces 1885A for score-reproduction testing; they are not part of
  a 2026 submission.

## Material-handling record

- The 2023 public attachment could not be downloaded without passing Codeforces'
  access challenge during this research session. It was not obtained through an
  authenticated or private route.
- Public files saved during the live challenge must be hashed with
  `tools/inventory_materials.py` before modification or unpacking.
- Any later third-party dependency must be added here with exact version, URL,
  license, files used, and reason before submission.
